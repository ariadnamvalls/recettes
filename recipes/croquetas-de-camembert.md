# Preparación

## Paso 1

Se hace la bechamel: en una cazuela se vierten {{ 50g de mantequilla }}, se deja deshacer y se vierten {{ 60g de harina }}. Se deja *tostar* removiendo todo el rato y luego se echa {{ 1/2 l de leche }}.

## Paso 2

Cuando queda una masa compacta se separa del fuego y se le echan las yemas de {{ 2 huevos }} y {{ 1/2 camembert (redondo) }} a trozos. Se coloca otra vez en el fuego para que el queso se deshaga.

## Paso 3

Se coge una fuente, se le echa un poco de {{ aceite }} y se pone la masa. Se deja *enfriar* en la nevera.

## Paso 4

Cuando ya esté fría se retira, se le da la forma y se pasa 1º por harina, 2º por las claras de huevo y 3º por {{ pan rallado }}.

## Paso 5

*Freírlas* en abundante aceite.
