# Preparación

## Paso 1

*Cortar* {{ 300g de calabaza }} en dados y *asarla* con {{ 250g de tomates cherry }}, {{ aceite de oliva }} y {{ sal }} 25min a **200ºC**.

## Paso 2

*Cocer* {{ 150g de arroz }} y dejar enfriar.

## Paso 3

*Mezclar* el arroz con las verduras asadas, {{ 1 puñado de guisantes }}, {{ 100g de feta }} desmigado y {{ 2 cdas de semillas tostadas }}.
