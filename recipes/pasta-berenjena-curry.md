# Preparación

## Paso 1

Se ponen en el horno {{ 4 berenjenas grandes }} y se dejan *cocer*. Cuando estén hechas se les saca la pulpa.

## Paso 2

En una sartén se *fríen* {{ 2 ajos }} en trocitos, luego se echan {{ 2 cebollas grandes }} cortadas a tiras finas y se dejan *dorar*. Añadir {{ curry }}, {{ 1 dado de caldo vegetal }} y {{ laurel }}.

## Paso 3

Se echa la pulpa de las berenjenas y se sigue *friendo* hasta que se vea bien reducido. Todo se fríe con abundante {{ aceite }}.

## Paso 4

Servir con {{ espaguetis }}.
