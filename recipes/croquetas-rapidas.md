# Preparación

## Paso 1

Se *fríe* {{ cebolla }} cortada a cuadraditos pequeños con {{ ajo }} machacado. Opcional: {{ queso }} u otras {{ verduras }}.

## Paso 2

Se añade un poco de {{ harina }} y de {{ leche }} para ligar.

## Paso 3

Se junta con el {{ pan rallado }} (la mezcla) y se hacen formas de croquetas con dos cucharas. Finalmente se pasan por pan rallado.

## Paso 4

Se *fríen*.
