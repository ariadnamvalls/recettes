# Preparación

## Paso 1

*Mezclar* {{ 125g de harina de trigo sarraceno }} con {{ 300ml de agua }} y una {{ pizca de sal }}, y dejar reposar 30min.

## Paso 2

*Dorar* {{ 2 patatas }} en dados en la sartén con {{ aceite }}. *Saltear* {{ 200g de espinacas }}.

## Paso 3

*Hacer* las galettes en una sartén bien caliente, *rellenarlas* con las patatas, las espinacas y {{ 80g de queso (de cabra o rallado) }}, y *doblarlas* hasta que el queso se funda.
