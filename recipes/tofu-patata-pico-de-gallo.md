# Preparación

## Paso 1

*Cortar* {{ 2 patatas }} y {{ 200g de tofu }} en dados, *aliñar* con {{ aceite de oliva }}, {{ sal }} y {{ pimentón }}, y *hornear* 35min a **200ºC**.

## Paso 2

Para el pico de gallo, *picar* {{ 2 tomates }}, {{ 1/2 cebolla }} y {{ cilantro }}, y *aliñar* con el {{ zumo de 1/2 lima }}, aceite y sal.

## Paso 3

Servir la patata y el tofu con el pico de gallo.
