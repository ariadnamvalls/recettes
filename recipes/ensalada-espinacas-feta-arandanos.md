# Preparación

## Paso 1

*Cortar* {{ 150g de polenta fría (o tofu) }} en dados y *dorarlos* en la sartén con {{ aceite de oliva }}.

## Paso 2

*Mezclar* {{ 100g de espinaca baby }} con {{ 100g de feta }} desmenuzado, {{ 1 puñado de arándanos }}, {{ 2 cdas de pipas de calabaza }}, {{ menta }} y {{ perejil }} picados.

## Paso 3

*Aliñar* con aceite, {{ zumo de limón }} y {{ sal }}, y *añadir* los dados crujientes por encima.
