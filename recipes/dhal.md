# Preparación

## Paso 1

Se *sofríe* {{ 1 diente de ajo picado }} y {{ 1/2 cebolla picada }} con un buen chorro de {{ aceite de oliva }}, removiendo durante unos pocos minutos.

## Paso 2

Añadir la mezcla de especias: {{ 1/4 cdta de cúrcuma }}, {{ 1/2 cdta de garam masala }}, {{ 1/4 cdta de cayena }} y {{ 1/2 cdta de comino }}. Dejar unos segundos más.

## Paso 3

Añadir {{ 500g de tomate cortado en dados }}, {{ 87,5g de lentejas rojas }}, el {{ zumo de 1/2 limón }}, {{ 300ml de caldo de verduras }} (o agua de verduras) y {{ 150ml de leche de coco }} (cuando no tengo no se la pongo y también queda rico).

## Paso 4

*Llevar a ebullición* y bajar el fuego. Dejar que se cocine 25-30min.

## Paso 5

*Salpimentar*.
