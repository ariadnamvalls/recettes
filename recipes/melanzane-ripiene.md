# Preparación

## Paso 1

Se *hierven* las {{ berenjenas }} o se ponen un poco al horno para que se pueda sacar bien la pulpa. La cáscara se tritura un poco abajo y un poco arriba.

## Paso 2

Se hace una pasta de {{ arroz }} + {{ huevo }} (crudo, opcional) + {{ queso }} + {{ alcaparras }} + {{ olivas }} + {{ perejil }} + {{ tomate seco }} (opcional).

## Paso 3

Se *rellenan* las berenjenas. Poner {{ tomate }} en la base de la bandeja, las berenjenas encima y por encima {{ pan rallado }}.

## Paso 4

*Hornear*.
