# Preparación

## Paso 1

*Mezclar* {{ 200g de semillas }} (girasol, calabaza, sésamo, lino) con {{ 50g de copos de avena }} y {{ 3 cdas de sirope de arce o miel }}.

## Paso 2

*Extender* la mezcla en una bandeja con papel de horno, *apretando* bien, y *hornear* 20min a **170ºC**.

## Paso 3

*Dejar enfriar*, *cortar* en barritas y, si se quiere, *bañar* con {{ 50g de chocolate negro }} fundido.
