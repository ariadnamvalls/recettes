# Preparación

## Paso 1

*Cortar* a trocitos pequeños {{ zanahorias }}, {{ cebollino }}, {{ pepino }} y {{ cacahuetes }}. Los {{ noodles fritos }} solo se trocean.

## Paso 2

*Mezclar* {{ crema de cacahuete }}, {{ jengibre }}, {{ salsa de soja }}, {{ salsa picante }}, {{ lima }}, {{ ajo }} y {{ aceite }} para hacer la salsa.

## Paso 3

Usar las hojas de {{ cogollos de lechuga }} como base, poner los toppings y finalmente la salsa.
