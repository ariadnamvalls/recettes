# Preparación

## Paso 1

Para la masa: *pelar* {{ 1kg de yuca }} y sacarle el centro. Ponerla a *hervir* hasta que esté cocida (pero no muy pasada).

## Paso 2

*Molerla* o pasarla por el pasapurés para hacer una masa. Añadir {{ 2 cdas de mantequilla }} y {{ sal }}, y *amasar* todo. Si queremos, añadir un poco de {{ harina de trigo o maicena }} (unas 2 cdas).

## Paso 3

Para el relleno: *cocinar* {{ 3/4 taza de arroz }} con {{ 1 pastilla de caldo }}. Hacer un hogao con {{ 2 tomates }}, {{ 1/2 cebolla }} y {{ 1/2 pimiento }}, y juntarlo con el arroz.

## Paso 4

*Dividir* la masa en 8 bolas, extenderlas tipo arepa, poner el relleno y cerrar. Darles forma de huevo alargado.

## Paso 5

*Freír* en abundante {{ aceite }}. Servir con {{ ají }}.
