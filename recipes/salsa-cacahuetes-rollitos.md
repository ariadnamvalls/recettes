# Preparación

## Paso 1

*Picar* {{ 1 diente de ajo }} y {{ 1 trozo de jengibre }} pelado.

## Paso 2

*Triturar* con {{ 1/2 taza de anacardos o maní }}, {{ 2 cdas de tamari }}, {{ 2 cdas de jarabe de arce }} (opcional), {{ 2 cdas de zumo de limón }} y {{ chile en polvo }} (opcional).

## Paso 3

Añadir {{ 1/3 taza de agua }} poco a poco, hasta conseguir la textura deseada.

## Paso 4

Servir con rollitos de {{ papel de arroz }} rellenos de {{ fideos de arroz }}, {{ tofu }}, {{ zanahoria }}, {{ lechuga }} y {{ hierbas frescas }}.
