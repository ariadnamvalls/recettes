# Preparación

## Paso 1

*Cortar* {{ 2 puerros }} finos en media luna.

## Paso 2

*Sofreírlos* con {{ 1 ajo }} y {{ aceite }}.

## Paso 3

A media cocción, poner {{ 2 manojos de espárragos verdes }} cortados en trocitos y seguir sofriendo con {{ hierbas provenzales }}.

## Paso 4

Añadir un chorro de {{ Dry Sack }} y {{ 1 pastilla de caldo vegetal }}. Dejar hasta que el alcohol se evapore.

## Paso 5

Añadir {{ 1 crema de leche de soja }} y *cocinar* unos minutos para que se amalgame bien.

## Paso 6

Servir, opcionalmente, con {{ parmesano }} y {{ avellanas }}.

# Consejos

Este plato puede ser de acompañante o también para hacer con pasta tipo trofie.
