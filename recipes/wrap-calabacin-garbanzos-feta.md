# Preparación

## Paso 1

*Cortar* {{ 1 calabacín }} en dados y *asarlo* a la plancha. *Tostar* en la sartén {{ 1 bote de garbanzos cocidos }} con {{ aceite de oliva }} y {{ comino }}.

## Paso 2

*Mezclar* {{ 150g de yogur }} con {{ eneldo }}, {{ menta }}, {{ limón }} y {{ sal }}.

## Paso 3

*Calentar* {{ 2 tortillas de trigo }} en la plancha, rellenar con el calabacín, los garbanzos, {{ 100g de feta }} desmigado y el yogur, y *enrollar*.
