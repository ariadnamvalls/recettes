# Preparación

## Paso 1

Se corta {{ 1 ajo }} en trocitos y se *fríe*.

## Paso 2

Se le echa {{ 1 cdta de mantequilla }}, se deshace y se le echan {{ 250g de gorgonzola }}.

## Paso 3

Cuando está líquido se le echa {{ 1 bote de nata espesa para cocinar }} y por último {{ 50g de parmesano }} (a gusto).

## Paso 4

*Mezclar* con la {{ pasta }}.
