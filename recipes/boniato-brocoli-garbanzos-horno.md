# Preparación

## Paso 1

*Cortar* {{ 1 boniato }} en dados y {{ 1 brócoli }} en ramitos. *Escurrir* {{ 400g de garbanzos cocidos }}.

## Paso 2

*Aliñar* todo con {{ aceite de oliva }}, {{ sal }} y {{ pimienta }} y *hornear* 30min a **200ºC**.

## Paso 3

Servir con {{ perejil fresco }} y {{ eneldo }} picados por encima.
