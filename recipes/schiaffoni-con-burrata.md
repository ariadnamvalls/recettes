# Preparación

## Paso 1

*Saltear* {{ 1 puerro }}.

## Paso 2

Cuando el puerro esté medio hecho, añadir {{ tomates cherry }} cortados por la mitad con {{ ajo }}, {{ aceite }} y {{ hierbas provenzales }}.

## Paso 3

Una vez salteados, añadir la {{ burrata (una para dos) }} y {{ caldo de verduras o de pollo }} hasta formar una salsa. Dejar *cocinar* un poquito hasta que quede todo amalgamado.

## Paso 4

*Cocer* los {{ schiaffoni }} y echarlos cuando estén hechos directamente del agua (es decir, sin colarlos). *Amalgamar* todo al fuego y añadir {{ albahaca }} y {{ parmesano }}.

# Consejos

Se puede hacer sin puerro si no se tiene y, si no tenemos caldo, diluir una pastilla de caldo en agua.
