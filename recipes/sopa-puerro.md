# Preparación

## Paso 1

*Cortar* {{ puerros }} (o cebolla) finitos y *sofreírlos* con {{ aceite }} a fuego muy bajo y lento.

## Paso 2

Añadir un chorrito de {{ vino blanco }}.

## Paso 3

Cuando ya esté cocido, añadir {{ agua }}, {{ caldo de verduras }} y las hierbas ({{ orégano }}, {{ romero }}, {{ tomillo }}) y *hervir* durante un rato.
